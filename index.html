    Cara pakai

    • Tekan tombol mic (atau spasi) lalu sebut kata kuncinya. Mic tetap nyala sampai dimatikan, jadi bisa nanya berturut-turut.

    • Tombol Acak buat latihan mandiri: entri muncul acak, tebak dulu isinya baru baca.
    • Mic butuh Chrome/Edge, koneksi internet, dan situs harus diakses lewat https (atau localhost).
    • Mau tambah/ubah data? Edit file data.js, lalu deploy ulang.
